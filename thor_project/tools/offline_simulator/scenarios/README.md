# 场景目录

后续每个场景使用一个独立目录，至少包含：

- `scenario.json`：工作面、障碍物、初始关节和回放速度。
- `actions.jsonl`：候选动作序列或录制轨迹。
- `expected.json`：应通过、应拒绝和截止时间预期。
- `README.md`：场景目的、数据来源和限制。

第一批计划场景：

1. 安全姿态，不接近工作面。
2. 末端垂直靠近工作面。
3. 两个采样点之间穿越工作面。
4. 上一步动作安全、下一步动作危险，验证保持上一步。
5. 上一步也因最新反馈变得不安全，验证保持测量姿态。
6. 安全计算超过 8 ms，验证截止时间策略。
7. 关节越界、速度越界、加速度越界。

所有场景均为离线数据，不包含机器人地址和控制凭据。
