# 系统架构与通信流程

## 1. 组件架构

```text
┌──────────────────── 本地浏览器 ────────────────────┐
│ 三维场景 │ 参数面板 │ 轨迹回放 │ 性能与告警         │
└────────────────────────┬───────────────────────────┘
                         │ HTTP + WebSocket
                         │ 仅仿真命令/最新姿态/统计
┌────────────────────────▼───────────────────────────┐
│              Nexus Simulator 服务（8766）           │
│ 会话管理 │ 场景管理 │ 最新帧缓冲 │ 报告生成          │
├────────────────────────┬───────────────────────────┤
│ 运动学/MuJoCo          │ Nexus 安全计算适配器        │
│ 关节、接触、场景状态   │ 工作面、路径、拒绝策略     │
├────────────────────────┴───────────────────────────┤
│ 离线 URDF 快照 │ 离线 action 轨迹 │ 仿真配置           │
└────────────────────────────────────────────────────┘

不存在：GDK、机器人 IP、SSH 控制、模型服务动作下发
```

## 2. 页面加载流程

1. 浏览器访问仿真服务。
2. 服务读取仿真配置并进行 fail-closed 校验。
3. 校验 `simulation_only=true`、`calibrated=false`、`deployable=false`。
4. 加载固定版本的 G2 URDF 与 mesh 快照。
5. 创建仿真会话并返回资源版本、关节列表、工作面参数。
6. 浏览器创建三维场景。
7. 服务发送初始姿态和诊断结果。

任一隔离字段或资源哈希不匹配时，不创建会话。

## 3. 单步动作验证流程

```text
浏览器/离线轨迹
      │ candidate action
      ▼
动作格式与关节映射校验
      │
      ▼
根据当前仿真 joints 计算路径采样点
      │
      ▼
同步工作面安全检查 ──────危险──────┐
      │安全                         │
      ▼                             ▼
仿真推进一步                重检上一安全动作
      │                       │安全       │不安全
      ▼                       ▼           ▼
更新 joints/接触          保持上一步   保持测量姿态
      └──────────────┬───────────┬────────┘
                     ▼
           最新姿态 + 决策原因 + 耗时
                     │
                     ▼
                 浏览器显示
```

仿真“保持测量姿态”指保持当前仿真状态，不涉及真实设备。

## 4. 连续回放流程

后端安全循环以目标 100 Hz 运行：

1. 取下一个候选动作。
2. 执行同步安全检查并记录耗时。
3. 选择安全动作、上一步动作或当前姿态。
4. 更新仿真状态。
5. 将结果覆盖写入单槽位 `latest_frame`。
6. 浏览器广播任务最多以 30 FPS 读取 `latest_frame`。

如果浏览器来不及消费，旧显示帧直接丢弃；安全循环不等待前端。

## 5. 浏览器命令

第一阶段只接受以下白名单命令：

- `load_scenario`
- `set_work_surface`
- `set_joint_state`
- `step`
- `play`
- `pause`
- `reset`
- `export_report`

不接受 shell、环境变量、SSH 地址、任意文件路径、GDK 方法名或原始 Python 代码。

## 6. SSH 访问

优先直接使用服务器内网地址：

```text
http://<服务器IP>:8766
```

端口不可直达时：

```bash
ssh -L 8766:127.0.0.1:8766 <服务器SSH地址>
```

浏览器访问 `http://127.0.0.1:8766`。该方案只转发 Web 流量，不传输桌面画面。

## 7. 后续与 Nexus Platform 的通信

成熟后由 Nexus Platform 创建“仿真计划”，仿真器返回独立会话 ID。双方只交换稳定 JSON，不共享进程内状态。

```text
Nexus Platform ──创建仿真计划──> Nexus Simulator
Nexus Platform <──session_id──── Nexus Simulator
浏览器       ──WebSocket──────> Nexus Simulator
Nexus Platform <──摘要/报告───── Nexus Simulator
```

真机部署 API 与仿真 API 必须使用不同路径、不同数据类型和不同权限。
