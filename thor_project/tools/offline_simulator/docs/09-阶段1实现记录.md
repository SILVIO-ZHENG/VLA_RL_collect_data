# 阶段 1 实现记录

日期：2026-08-14。

## 已完成

- 原型阶段曾使用 Python 3.11 独立 `.venv`；迁入 Nexus 后改用根目录统一 workspace 环境。
- 安装 MeshCat 0.3.2、yourdfpy 0.0.60 和开发测试依赖。
- 从 LeRobot 权威目录同步完整 G2 URDF/mesh 快照。
- 生成并校验 60 个文件的 SHA-256 清单。
- 加载 `G2_omnipicker_visual.urdf`。
- 识别 32 个自由度、28 个可调关节。
- 解析 94 个保留材质的几何对象，共 596006 个三角面。
- 使用 yourdfpy 更新关节配置和 mimic 关节 FK。
- 使用 MeshCat 显示 G2、工作面和硬安全余量。
- 实现普通浏览器控制页，支持关节滑块、工作面高度、硬余量和姿态复位。
- HTTP API 对未知关节、越界数值、非有限数值和过大请求体 fail closed。
- 页面明确显示 `SIMULATION ONLY`，服务中没有 GDK 或机器人入口。

## 当前进程结构

```text
nexus-sim serve
├── HTTP 控制服务        8766
├── MeshCat Web 服务     8767
├── MeshCat ZMQ bridge   本机内部端口
└── G2 URDF/FK 模型      仅内存状态
```

控制页通过 HTTP 修改内存中的关节配置；后端计算 FK 后只更新 MeshCat 几何变换。

## 当前限制

- 控制页和 MeshCat 使用两个端口，SSH 使用时需同时转发。
- 首次浏览器连接需要传输约 45 MB G2 网格。
- 当前只是 FK 可视化，不是动力学仿真。
- 当前工作面是有限大小的显示网格，安全配置语义仍是 `xy_bounds=null` 的无限平面。
- 尚未与生产安全层进行黄金输入逐项对比。
- yourdfpy 和 MeshCat 只用于可视化/FK，不作为未来 100 Hz 安全判断的权威实现。

## 下一步建议

先由用户人工检查：

1. G2 外观是否完整。
2. 左右臂关节方向是否符合认识。
3. 夹爪 mimic 展开是否合理。
4. 工作面在 `base_link` 下的位置是否符合预期。
5. 通过内网或 SSH 双端口转发是否流畅。

人工确认后进入阶段 2：导入合成 action 轨迹、复用生产安全数学逻辑、显示碰撞球与动作拒绝分支。
