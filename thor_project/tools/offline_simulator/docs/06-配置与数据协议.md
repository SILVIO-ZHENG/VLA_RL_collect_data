# 配置与数据协议

本文是实现前的协议草案，阶段 1 可根据实际 URDF 导入结果修订，但安全隔离字段不得放宽。

## 1. 仿真配置

权威示例见 `configs/g2_work_surface.simulation.json`。

关键字段：

| 字段 | 约束 | 说明 |
|---|---|---|
| `profile` | 非空字符串 | 配置名称 |
| `simulation_only` | 必须为 `true` | 禁止误用于真机 |
| `calibrated` | 必须为 `false` | 仿真默认值没有现场标定 |
| `deployable` | 必须为 `false` | 禁止部署 |
| `work_surface.frame` | 第一阶段固定 `base` | 工作面坐标系 |
| `work_surface.height` | 有限数值，米 | 唯一工作面高度 |
| `work_surface.hard_margin` | 有限且大于 0，米 | 硬安全余量 |
| `work_surface.xy_bounds` | `null` 或 `[xmin,xmax,ymin,ymax]` | `null` 为无限平面 |
| `guard.enabled` | 布尔值 | 默认 `true`；只控制是否执行拦截，不关闭检测 |
| `guard.path_samples` | 正整数 | 同步路径采样数 |
| `guard.deadline_ms` | 正数 | 默认 8 ms |
| `guard.max_consecutive_deadline_misses` | 正整数 | 默认 3 |
| `guard.collision_response` | 白名单枚举 | 默认保持上一步安全动作 |

## 2. 候选动作记录

建议使用 JSONL，每行一个周期：

```json
{
  "sequence": 42,
  "timestamp_s": 0.42,
  "joint_names": ["..."],
  "measured": [0.0],
  "candidate": [0.01],
  "source": "fixture"
}
```

约束：

- `sequence` 严格递增。
- joints 与 candidate 必须有限、长度一致。
- joint names 必须与资源清单完全一致且顺序一致。
- 第一阶段只支持绝对关节目标，其他空间必须显式转换。
- 不允许在记录中携带 Python pickle 或可执行内容。

## 3. 安全决策事件

```json
{
  "sequence": 42,
  "decision": "hold_previous_safe_action",
  "accepted": false,
  "reason": "collision_risk_hold_previous_safe_action",
  "surface": "work_surface",
  "point": [0.32, -0.18, 0.77],
  "minimum_clearance_m": -0.01,
  "guard_latency_ms": 2.7,
  "deadline_missed": false
}
```

事件用于显示和审计，不允许浏览器修改后再作为安全结果写回。

## 4. 最新显示帧

后端最多 100 Hz 产生结果，显示层最多 30 FPS 取最新帧：

```json
{
  "type": "simulation_frame",
  "session_id": "sim_...",
  "sequence": 42,
  "sim_time_s": 0.42,
  "joints": [0.0],
  "candidate_path": [],
  "applied_path": [],
  "collision_points": [],
  "decision": {},
  "performance": {}
}
```

WebSocket 消息只保留最新帧，不保证每个显示帧送达。完整安全事件另写入有界日志队列。

## 5. 报告元数据

每份报告必须包含：

- `simulation_only=true`
- 工程版本
- 场景哈希
- 配置哈希
- URDF 与 mesh 哈希
- 安全核心版本/哈希
- Python、MuJoCo、MeshCat 版本
- 开始与结束时间
- 性能统计和拒绝统计

缺少版本信息的报告只能用于临时调试，不能用于评审。
