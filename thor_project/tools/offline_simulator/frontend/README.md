# 浏览器可视化计划

阶段 1 前端已经实现：外层控制页运行在 8766，MeshCat WebGL 画面运行在 8767。它避免 SSH X11 和远程桌面，并支持工作面与 G2 关节的交互更新。

已经展示：

- G2 可视模型。
- 单一工作面及硬安全余量。
- 关节分组、关节滑块和 FK 姿态更新。
- 姿态复位、资源数量和哈希校验状态。

阶段 2 计划增加：

- 当前姿态、候选轨迹、安全输出轨迹。
- 碰撞球、最危险点、最小距离。
- 绿色安全、黄色裁剪、红色拒绝、蓝色保持上一步。
- 单步、连续播放、暂停和复位。
- 100 Hz 安全计算统计与 30 FPS 浏览器显示统计。

前端只操作仿真会话，不出现机器人 IP、SSH、GDK 或“真机执行”按钮。
