# 人在环路平板逐包采集操作手册

入口：[Thor 运行配置页面](http://192.168.110.14:21865/session.html)；在 Thor–G2 直连网络可用 `http://10.42.1.77:21865/session.html`。当前流程是一包一份平板录制，同一次 Nexus 任务可连续采集多包。平板控制原始录制，Nexus 观察录制并生成侧车数据；录制开始不会自动开启 Policy。

## 1. 现场与工作站准备

1. 清空机器人工作区，确认急停可用；停止其他占用 G2 控制权的 GDK 任务。在页面「控制权与任务准入」点击「检测机器人」，确认机器人空闲。
2. 确认工作站为「人工控制」。若显示「调度控制」，点击「人工接管」。本流程不由调度 API 启动。
3. 如页面显示「机器人待复位」，先按页面提示完成复位并等待成功。真机配置「保存并应用到工作站」本身也可能触发安全复位；复位包含夹爪和身体关节运动，因此应用前同样要清空工作区并确认急停可用。

## 2. 勾选人在环路并应用配置

1. 若要更换模型或 checkpoint，先去「模型部署」页选定 G2、模型和版本；沿用当前已加载模型可跳过。回到「运行配置」页，核对配置摘要；推理模式可选同步、异步或 RTC，按本次任务需要设置执行频率等参数。人在环路回退要求 **100 Hz 伺服**和已批准的工作区安全配置。
2. 硬件模式选「真机执行」，勾选「人在环路（VR 接管、回退与逐包采集）」。如果要在一次 Nexus 任务内连续录多个包，建议把「执行时长」设为 **0（一直执行）**，避免定时结束中断后续录制。
3. 点击「保存并应用到工作站」，确认弹窗，等待应用、模型和复位流程完成。页面可能跳转到一份新的任务配置；以跳转后的页面为准。确认任务处于「等待开始」，并且配置摘要是预期的模型、推理模式和真机模式。
4. 若工作站显示「新任务入口已关闭」，在复位成功且机器人空闲后点击「核实后允许新任务」。最终应看到「已获准启动；现在可在平板点击开始采集」。**看到这句话之前，不要在平板开始本次录制。**

## 3. 第一包：平板启动，手柄开启 Policy

1. 确认平板没有正在录制的旧任务，手柄 X/Y 和两侧接管键都先松开。
2. 在 G2 平板点击「开始采集」。G2 检测到唯一的新录制后，Thor 会走与网页「启动真机」相同的任务准入流程。页面先显示「检测到新录制」，随后进入「任务启动中／任务运行中」。这个平板入口不需要在网页双击「启动真机」，也不需要双击 Y。
3. 等机器人客户端确认 **HOLD**、页面显示任务运行且 Safe hold 已接入。此时机器人保持，不会自动执行 Policy。确认现场安全后，**按一次 Y 并松开**，Policy 才开始运动。若启动时 X/Y 仍按着，先完全松开并等一个中立手柄帧，再重新按 Y。
4. 本包完成后，在平板停止并保存这份录制。G2 会等待平板写完最终文件，再校验并封存这包的 Nexus 侧车。不要在平板保存前结束 Nexus 任务。

## 4. 手柄按键

| 操作 | 作用 |
| --- | --- |
| Y 按一次 | 在 HOLD 中开启 Policy；Policy 运行中再按一次，立即回到 HOLD。平板启动后只需一次 Y。 |
| X 按住 | 停止正在运行的 Policy，并请求沿已执行轨迹回退；持续按住才会持续回退。规划和执行前还要通过新鲜手柄帧及安全检查。 |
| X 松开 | 如果回退已经在执行，会沿**同一回退计划继续到选定的较早推理锚点**后停在 HOLD；因此松开 X 不等于立即原地停止。若只是很短地按了一下 X，可能仅停止 Policy 而没有形成回退计划。 |
| 左／右侧接管键 | 请求对应手臂交给人工控制；实际控制权以 G2 厂商仲裁状态为准。松开后须完成安全交还，才能再次由 Policy 控制。 |
| 手柄上扳机 | 人工控制时对应夹爪的输入；不是 Nexus 任务启动键。 |

遇到异常运动使用现场急停，不依赖网页或回退手势代替急停。

## 5. 第二包及结束

第一包保存并封存后，**不要点击网页「结束任务」**。直接在平板开始第二份新录制；G2 会在同一 Nexus 任务内把它绑定到新的 HOLD。确认 HOLD 后，再按一次 Y 开始第二包的 Policy。之后每包重复「开始一份录制 → Y → 平板保存 → 等待封存」。每份录制对应一个包，不要让两份录制同时处于活动状态。

全部包裹都保存并封存后，再在网页点击「结束任务」。下一次重新启动真机任务前，按页面提示完成必要复位和准入核实。

## 6. Thor 离线校验与归档

平板保存后的 G2 侧车封存是自动的；**Thor 拉取、离线校验和归档目前需要对每包单独运行命令，网页没有自动归档按钮**。可让维护人员在 Thor 执行，`<UUID>` 是 G2 `/data/logs/flowpro_sidecar` 中该包 `.sealed` 目录的名称（去掉 `.sealed`）：

```bash
cd /home/anu/deploy/nexus_deploy_hil_live_20261016_r1
PYTHONPATH=src .venv/bin/python -m nexus_deploy.robot.g2a.hitl.offline <UUID> \
  --staging-root runtime/thor/hitl-staging \
  --store-root runtime/thor/hitl-raw-store
```

命令成功会输出 `record_name`、`bundle_id` 和校验结果；原始平板数据仍保留在 G2。训练接入不在当前阶段。

## 常见阻挡

- 页面显示「检测到已有录制」：先在平板结束并保存旧录制，待监听恢复后再开始新的录制。
- 页面显示「检测到多份活动录制」：结束多余录制，确保只有本次唯一的新录制。
- 页面显示「监听不可用」或「启动未通过准入」：检查 G2 连接、工作站是否允许新任务、当前配置是否已应用、机器人是否空闲。此时不要反复按 Y；先处理页面阻挡。
- 已开始录制但未看到 HOLD：不要按 Y；保持现场安全，查看任务状态和 G2 日志。若录制提前结束或身份变化，系统不会拿另一份录制代替它启动 Policy。
