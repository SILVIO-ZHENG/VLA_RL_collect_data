03

运行参数

默认值来自部署服务，可按任务需要调整。

ASYNC 异步模式参数配置提前请求、重规划与延迟统计窗口。
高级参数 重规划、滤波、运动与跟踪阈值

动作滤波 截止频率必须低于伺服频率的一半
运动限制 最终下发前的速度与加速度上限
跟踪误差 命令与反馈偏差超过阈值时停止任务
04

安全策略

核心安全防护在当前部署协议中强制开启。

3 项强制
通信看门狗推理超时后立即进入动作保持。
运动学限制限制关节位置、速度与加速度。
跟踪误差保护连续偏差超过阈值时中止下发。
手臂低通滤波（可选）默认使用连续轨迹规划；需要时再启用低通。
末端低通滤波（可选）默认保留夹爪事件时序，仅按需启用。
保持末端执行器夹爪保持启动时测得的位置。
